# Нагрузочное тестирование
## Запуск проекта
* Перейти в корень проекта
* Запустить проект с помощью Docker,
выполнив команду ```docker compose up --build```

## Запуск тестов
* Установить Jmeter
* Скопировать путь к конфигу тестов в папке проекта (```jmeter/test.jmx```)
* Определить произвольные пути к файлу рещзультата (.jtl) и директорию отчёта
* Выполнить команду ```\путь\к\конфигу\jmeter\test.jmx" -l \путь\к\файлу\результата.jtl -e -o \путь\к\директории\отчёта```
* Дождаться завершения теста (может занять до 10 минут, т.к приложение плохо справляется с нагрузкой)
* После завершение перейти в директорию отчёта и открыть страницу index.html

## Сценарий тестирования
* Создать спутник
* Получить данные спутника
* Обновить данные спутника
* Создать группироваку
* Добавить спутник в группировку
* Получить данные группировки
* Получить сведения о группировках
* Удалить спутник с исключением из группировки
* Удалить группировку

P.S Для удобства файл результата и отчёт добавлены в папку jmeter (jmeter/result/ и jmeter/report/ соответсвтенно)
